# Module 4 Coding Assignment

## HTML, CSS, and JavaScript for Web Developers

This project is part of the **Module 4 Coding Assignment** for the Coursera course *HTML, CSS, and JavaScript for Web Developers*.

## Project Overview

The purpose of this project is to practice JavaScript fundamentals by iterating over an array of names and displaying a greeting in the browser console.

- Names beginning with **J** or **j** receive a `Good Bye` message.
- Names beginning with any other letter receive a `Hello` message.

## Technologies Used

- HTML5
- JavaScript
- Browser Developer Tools

## Key Concepts Practiced

- Immediately Invoked Function Expressions (IIFEs)
- JavaScript objects and methods
- Global scope and encapsulation
- Arrays and `for` loops
- String methods such as `charAt()` and `toLowerCase()`
- Conditional statements
- Using the browser console for debugging

## How to Run

1. Clone or download this repository.
2. Open the `module4-solution` folder.
3. Open `index.html` in a web browser.
4. Open the browser Developer Tools using `F12`.
5. Select the **Console** tab to view the output.

## Learning Objective

This assignment demonstrates how JavaScript functions, objects, arrays, loops, and conditional statements can work together to produce different outputs based on string values.
